# TreasureBench Agents v1 record instructions

- These files register DD-010 instrument and evaluation boundaries; they do not
  allocate DD-023, create a claim, or authorize execution.
- Preserve frozen campaign/history records, compatibility names, quarantined
  decisions, fresh-identity requirements, custody boundaries, and explicit
  no-base-authority fields.
- Public records contain only authorized public fixtures or redacted aggregate
  engineering state. Never include private tasks, answers, keys, prompts,
  outputs, traces, metric rows, dimension breakdowns, rankings, or composites.
- Any new private campaign, route, price, call, cap, or custody state requires
  a separately committed task contract and owner gate.
