## Translation into testable mechanisms

Keep advance planning, directed exploration, random action, social imitation, responsiveness, persistence, implementation ability, and reliability separate. A person can plan exploration, adapt reliably, or spontaneously copy a crowd. The experiments model behavioral policies, not human personality categories.

The core question is whether persistent differences between agents add value beyond equal-budget homogeneous policies, adaptive generalists, rotating roles, and explicit coordination. Count search costs, duplicate actions, execution failures, and private versus collective returns when the registered model contains them. Preserve null results and parameter regions where diversity loses.
