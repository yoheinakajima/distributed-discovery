# Release-record instructions

- Release records describe directly verified external state; they do not
  create scientific evidence or paper lifecycle status.
- Preserve exact source revisions, asset hashes, archive contents, version and
  concept identifier roles, licensing boundaries, and failed observations.
- External publication requires a separate exact owner gate. Offline
  preparation never implies that a tag, release, deposit, or DOI exists.
- Do not infer remote state from a local candidate or pasted output.
