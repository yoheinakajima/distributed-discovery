# Site instructions

- Generate public pages only from canonical tracked sources and validated
  immutable evidence; do not recompute scientific results in presentation code.
- Preserve route compatibility, source provenance, exact downloads, semantic
  structure, accessibility, keyboard use, mobile containment, and
  no-JavaScript fallbacks.
- Keep the site static, public-safe, no-tracking, and free of secrets, private
  material, credentials, local paths, and unverified external states.
- Site language may explain but may not strengthen claim, proof, paper, or
  evidence status.
- Deploy only through the authorized Pages workflow on `main`, then verify
  workflow state and live routes when the task includes deployment.
